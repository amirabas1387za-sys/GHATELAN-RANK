# GHATELAN RANK | قاتلان رنک

ربات تلگرام فارسی برای ثبت دستی امتیاز بازیکنان، رتبه‌بندی هفتگی و نگهداری سوابق.

## امکانات نسخه اولیه
- منوی فارسی بازیکن و مدیر
- افزودن بازیکن با شناسه داخلی KR-000001
- ثبت امتیاز با انتخاب دک، بازیکن، امتیاز و تأیید نهایی
- جدول هفتگی، سه نفر برتر و جدول کل
- پروفایل و ۳۰ سابقه اخیر بازیکن
- دسترسی مدیریتی با شناسه عددی تلگرام
- ذخیره‌سازی SQLite

## نکته مهم
این نسخه یک MVP اجرایی اولیه است، نه نسخه نهایی آماده پرداخت جایزه. اصلاح/حذف رکورد، خروجی اکسل، ثبت پرداخت جایزه، جلوگیری از ثبت تکراری بازی، اعلان خودکار پایان هفته و پنل مدیریت پیشرفته هنوز پیاده‌سازی نشده‌اند. پیش از استفاده رسمی و پرداخت جایزه باید تست و تکمیل شود.

## راه‌اندازی
1. در BotFather ربات را ساخته باشید.
2. روی هاست پایتون، فایل‌های این پروژه را بارگذاری کنید.
3. متغیرهای محیطی را تنظیم کنید:
   - BOT_TOKEN: توکن BotFather (محرمانه؛ هرگز در گروه یا چت عمومی نفرستید)
   - ADMIN_IDS: شناسه عددی مدیران، جداشده با کاما
   - TIMEZONE: Asia/Tehran
   - DECKS: نام چهار دک، جداشده با کاما
4. دستور نصب: `pip install -r requirements.txt`
5. دستور اجرا: `python main.py`

## توسعه محلی
Python 3.10 یا بالاتر پیشنهاد می‌شود.


## قوانین قطعی رقابت هفتگی
- هیچ حداقل یا سقفی برای تعداد بازی/ران در روز یا هفته وجود ندارد.
- هر تعداد بازی که برگزار شود، مدیر می‌تواند امتیازهای اعلام‌شده را ثبت کند.
- تمام امتیازهای ثبت‌شده در همان هفته در مجموع بازیکن محاسبه می‌شوند.
- برای حضور در جدول، حداقل تعداد بازی لازم نیست.
- با شروع هفته جدید، امتیاز رقابت هفتگی از صفر محاسبه می‌شود و سوابق هفته‌های قبل باقی می‌ماند.
- متن خوش‌آمدگویی ربات: «به بات تلگرامی خانواده قاتلان خوش آمدید.»
